# SpotdownRenamer
SpotdownRenamer es una extension o aplicacion que te ayuda a remover la marca de agua que tienen los archivos en el nombre que la eliminar automaticamente 

1.-Ocupar el programa, bueno descargas en releases el archivo llamado SpotdownRenamerPrograma.zip lo descomprimen y tendrán un un .exe llamado SpotdownRenamer.exe lo ejecutan y seleccionan la carpeta de donde hayan descargado la musica y se renombrara automática mente 

2.-Ocupar extensión, para ocupar la extensión tienes que  descargar el archivo llamado SpotdownRenamerExtension.zip y extraerlo después tienes que ir a tu navegador entrar al apartado de extensiones y activar el modo desarrollador en la esquina izquierda y después darle a cargar extensión sin empaquetar y selecionar la carpeta que extrajiste de SpotdownRenamerExtension.zip
